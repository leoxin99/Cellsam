# 记录新实验 (Log New Experiment)

当完成一个实验后，按以下步骤记录：

## 1. 确定实验 ID

查看 `anti_test/experiments_log.md` 中的实验索引，确定下一个可用的 ID（E01, E02, ...）。

## 2. 更新实验索引

在文件开头的实验索引表中添加新行：

```markdown
| Exx | YYYY-MM-DD | 实验名称 | 主要结果 | ✅成功/❌失败/⚠️待观察 |
```

## 3. 添加实验详情

在文件中按以下模板添加新实验章节：

```markdown
## Exx: [实验名称]

**日期**: YYYY-MM-DD

**背景/假设**: 
[为什么做这个实验]

**方法**:
1. [步骤1]
2. [步骤2]
...

**参数**:
| 参数 | 值 |
|------|-----|
| ... | ... |

**结果**:
| 指标 | 值 |
|------|-----|
| ... | ... |

**分析**:
[为什么得到这个结果]

**结论**: ✅/❌/⚠️ [简短结论]

**代码位置**: [相关脚本路径]
```

## 4. 更新决策日志（如有重要决策）

如果实验结果导致重要决策，在 "关键决策记录" 表中添加：

```markdown
| YYYY-MM-DD | 决策内容 | 原因 |
```

## 5. 更新 results_summary.md（如有新数据）

如果有新的关键结果数据，同步更新 `anti_test/results_summary.md` 中的相关表格。
