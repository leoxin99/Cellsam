## 1. Per-Cell 损失计算 vs 整体掩膜损失 ⭐

**决策**: 采用 **Per-Cell 损失计算**

**问题背景**:
- ❌ **错误方法**: 将所有细胞的预测合并为一个整体掩膜，与 GT 整体掩膜计算 Dice
- ✅ **正确方法**: 每个细胞单独预测掩膜，与其对应的 GT 区域单独计算 Dice，然后平均

**理论依据**:
1. **实例分割的本质**: 任务目标是精确分割**每个独立细胞**，而非仅识别前景/背景

2. **数学公式对比**:
```
错误方法: Dice_overall = Dice(merge(all_predictions), merge(all_GT))
正确方法: Dice_per_cell = (1/N) * Σ Dice(pred_i, GT_i)
```

**论文表述**:
> "To ensure accurate instance-level segmentation quality, we compute loss on a per-cell basis rather than merging all predictions."

## 2. 训练时边界框选择: GT vs DAPI vs CellFinder ⭐⭐

**决策**: 训练阶段使用 **GT 边界框**，推理阶段使用 **DAPI 核检测**

| 方法 | 优点 | 缺点 | 适用阶段 |
|-----|------|------|---------|
| **GT 框** | 位置/大小完美 | 推理时不可用 | ✅ 训练 |
| **DAPI 框** | 推理时可用 | 核 ≠ 细胞体 | ✅ 推理 |
| **CellFinder** | 接近推理场景 | 心肌细胞检测差 | ❌ 不推荐 |

**为什么不用 DAPI (训练)?**
- 心肌细胞常见双核（一个细胞包含两个核）
- 核面积仅占细胞面积的 ~3%

**解耦策略**:
```
训练目标 = 学习"如何精确分割给定框内的细胞"
检测目标 = 学习"如何找到所有细胞的位置"
两个任务解耦，避免相互干扰
```

## 3. 百分位归一化 (P2-P98) vs Min-Max 归一化 ⭐

**决策**: 使用 **百分位归一化 (P2-P98)**

**Min-Max 的问题**:
```
一个异常像素 (I_max = 65535) 会压缩整个动态范围
大部分像素值挤压在 [0, 0.1] 范围
```

**百分位归一化的优势**:
```python
p2 = np.percentile(image, 2)
p98 = np.percentile(image, 98)
I_norm = np.clip((I - p2) / (p98 - p2), 0, 1)
```
- 自动适应不同曝光条件
- 鲁棒于异常值

## 4. 数据量选择: 20 vs 50 vs 478 张图像 ⭐

**决策**: 初步训练 **50 张**，完整训练 **478 张**

| 数据量 | 细胞数 | 过拟合风险 | 适用场景 |
|-------|--------|-----------|---------|
| 20 张 | ~252 | 高 | 快速测试 |
| 50 张 | ~630 | 中等 | 初步验证 ✅ |
| 478 张 | ~5173 | 低 | 完整训练 ✅ |

**迭代开发策略**:
```
50 张验证 → 调试优化 → 478 张完整训练
避免: 直接 478 张 → 发现问题 → 浪费时间
```

## 5. 边界框内损失计算与类别不平衡处理 ⭐⭐⭐

**问题**: 训练时验证 Dice 始终为 0.0000，模型预测全背景

**根本原因 - 严重类别不平衡**:
```
背景:前景比例 = 19:1
BCE Loss 推动模型预测"全背景"以最小化损失
```

**解决方案**:
1. **边界框内损失计算**: 仅在细胞边界框区域（扩展 20%）内计算，bg:fg 比例从 19:1 降至 ~2:1
2. **动态 pos_weight**: 根据每个样本的实际前景比例动态计算，上限 10.0

**修复效果**:
| 状态 | Dice Score |
|------|------------|
| 修复前 (bug) | 0.0000 |
| 修复后 | **0.4436** |

## 6. 解耦训练策略 (Decoupled Fine-tuning) ⭐⭐⭐

**决策**: 仅训练 Mask Decoder，冻结其他所有组件

**架构**:
```
┌─────────────────────────────────────────┐
│ Image Encoder (ViT-H)  │ ❄️ 冻结 │ 630M 参数 │
├─────────────────────────────────────────┤
│ Prompt Encoder         │ ❄️ 冻结 │           │
├─────────────────────────────────────────┤
│ Mask Decoder           │ 🔥 训练 │ 4M 参数   │
├─────────────────────────────────────────┤
│ CellFinder             │ ❄️ 冻结 │           │
└─────────────────────────────────────────┘
```

**理由**:
- 仅训练 Decoder → 训练速度提升 ~150x
- 显存需求降低 ~10x
- 避免在小数据集上过拟合
