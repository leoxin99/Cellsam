# 细胞分割评估指标详解

> **目的**: 帮助理解常用细胞分割评估指标
> **更新**: 2026-02-04

---

## 一、像素级指标 (Pixel-Level)

### 1.1 Dice Coefficient (Dice 系数)

**公式**:
```
Dice = 2 × |A ∩ B| / (|A| + |B|)
```

**直观理解**:
```
预测:  ████████░░    (8像素)
GT:    ░░████████    (8像素)  
重叠:    ████        (4像素)

Dice = 2×4 / (8+8) = 0.5
```

**范围**: 0 (完全不重叠) ~ 1 (完全重叠)

**优点**:
- 计算简单快速
- 对类别不平衡有一定鲁棒性

**缺点**:
- ⚠️ **不区分实例**: 10个细胞当成1个整体计算
- ⚠️ **大细胞主导**: 1个大细胞分割好 > 10个小细胞分割好
- ⚠️ **边界不敏感**: 边界模糊但大部分正确时仍然高

---

### 1.2 IoU (Intersection over Union)

**公式**:
```
IoU = |A ∩ B| / |A ∪ B|
```

**与 Dice 的关系**:
```
IoU = Dice / (2 - Dice)
Dice = 2×IoU / (1 + IoU)

IoU=0.5 ↔ Dice=0.67
IoU=0.7 ↔ Dice=0.82
```

## 二、实例级指标 (Instance-Level)

### 2.1 PQ (Panoptic Quality) ⭐ 最重要

**公式**:
```
PQ = SQ × RQ

SQ (Segmentation Quality) = Σ IoU(pred_i, gt_j) / TP
RQ (Recognition Quality) = TP / (TP + 0.5×FP + 0.5×FN)
```

**直观理解**:
```
RQ = "我检测到了多少正确的细胞？"
SQ = "检测到的细胞，分割得多准确？"
PQ = 两者的乘积
```

**匹配规则**:
- pred 和 gt 的 IoU > 0.5 → 匹配成功 (TP)
- pred 没有匹配到任何 gt → FP
- gt 没有被任何 pred 匹配 → FN

**示例**:
```
GT: 4个细胞
Pred: 5个预测

匹配结果:
- Pred1 ↔ GT1 (IoU=0.75) ✓ TP
- Pred2 ↔ GT2 (IoU=0.60) ✓ TP  
- Pred3 ↔ GT3 (IoU=0.35) ✗ 不匹配 (IoU<0.5)
- Pred4 无匹配 → FP
- Pred5 无匹配 → FP
- GT3 无匹配 → FN
- GT4 无匹配 → FN

TP=2, FP=3, FN=2
SQ = (0.75 + 0.60) / 2 = 0.675
RQ = 2 / (2 + 0.5×3 + 0.5×2) = 2/4.5 = 0.444
PQ = 0.675 × 0.444 = 0.30
```

---

### 2.2 AJI (Aggregated Jaccard Index)

**公式**:
```
AJI = Σ |pred_i ∩ gt_j| / Σ |pred_i ∪ gt_j|
```

**特点**:
- 考虑所有实例的聚合 IoU
- 比 PQ 更宽松 (无 IoU>0.5 要求)
- 过分割/欠分割都会降低分数

---

### 2.3 F1 @ IoU=0.5

**公式**:
```
Precision = TP / (TP + FP)
Recall = TP / (TP + FN)
F1 = 2 × P × R / (P + R)
```

**其中**: TP = IoU > 0.5 的匹配数

---

## 三、边界级指标 (Boundary-Level)

### 3.1 Hausdorff Distance (HD)

**公式**:
```
HD(A, B) = max(h(A,B), h(B,A))
h(A,B) = max_{a∈A} min_{b∈B} ||a-b||
```

**直观理解**: 两条边界之间的最大距离

**用途**: 检测边界的最差点

---

### 3.2 Boundary F1

**计算**:
1. 提取预测和GT的边界
2. 计算边界像素的精度和召回
3. F1 = 2PR/(P+R)

## 四、指标选择建议

| 任务 | 推荐指标 | 原因 |
|------|----------|------|
| 快速训练验证 | Dice | 计算快 |
| 实例分割质量 | **PQ** | 综合检测+分割 |
| 边界精度 | HD, Boundary F1 | 专注边界 |
| 论文报告 | PQ + AJI + Dice | 全面 |
