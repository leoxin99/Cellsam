# A1-H1b Handover

> 日期: 2026-03-12
> 角色: `A1-H1b`
> 目标: 实现 `H1bA`，把完整 `DAPI + Actn2` 检测先验注入 `CellFinder`
> 关系: 这是 `CellFinder` 结构改造路线，不是外部轻量 regressor

## 1. 任务定义

`H1bA` 的目标不是只复用“双核合并”和“核距离筛选”。

`H1bA` 第一版必须继承完整的现有 `DAPI + Actn2` 检测先验链：

1. `detect_nuclei()`
2. `merge_close_nuclei()`
3. `is_on_edge()`
4. `filter_by_actn2()` 或 `detect_cardiomyocytes()`
5. `detect_with_adaptive_box()` 路线中的 `debug_info / nucleus_center / adaptive box`
6. `locked_eval` 参数配置

这里的设计意图是：

1. `DAPI + Actn2` 负责 cardiomyocyte candidate identity
2. `CellFinder` 负责 whole-cell box extent refinement

## 2. 当前代码证据

released `CellFinder` 当前不支持外部 candidates，证据如下：

1. `cellSAM_source/cellSAM/sam_inference.py`
   - `CellfinderAnchorDetr.forward_inference(self, imgs, viz=False)`
   - `CellSAM.generate_bounding_boxes(self, images, device=None)`
2. `cellSAM_source/cellSAM/AnchorDETR/models/transformer.py`
   - `self.position = nn.Embedding(self.num_position, 2)`
   - `reference_points = self.position.weight...`

结论：

1. 这不是配置切换
2. 这不是原仓库已支持能力
3. 这是对当前 `CellFinder / AnchorDETR` 的明确代码改造

## 3. 当前默认路线

`H1bA` 第一版默认采用：

1. `strict prior-only`
2. `locked_eval` 检测参数
3. candidate 来源优先 `adaptive` 路线
4. 不默认保留大量 learned fallback queries

原因：

1. 当前项目经验判断是 `DAPI + Actn2` candidates 已经与 `GT` 很接近
2. 如果继续保留大量 fallback queries，会把 detector 拉回“全图自由搜索”
3. 那样会重新引入当前 `CellFinder` 的主要 `FP` 问题

`hybrid fallback` 只作为后续对照，不是第一版主路径。

    ...

1. 第一版 `CellFinder` 只强制使用 `candidate_points_norm`

## 7. 需要修改的 `CellFinder` 代码

### 7.1 `cellSAM_source/cellSAM/sam_inference.py`

#### 当前函数

1. `class CellfinderAnchorDetr(nn.Module)`
2. `forward(self, features=None)`
3. `forward_inference(self, imgs, viz=False)`
4. `class CellSAM(nn.Module)`
5. `generate_bounding_boxes(self, images, device=None)`

#### 建议改法

把这两个签名扩展为：

```python
def forward(self, features=None, candidate_points=None, candidate_valid_mask=None):
    ...

def forward_inference(
    self,
    imgs,
    viz: bool = False,
    candidate_points=None,
    candidate_valid_mask=None,
):
    ...
```

`CellSAM.generate_bounding_boxes()` 扩展为：

```python
def generate_bounding_boxes(
    self,
    images,
    device=None,
    candidate_points_per_image=None,
    candidate_valid_masks=None,
):
    ...
```

第一版要求：

1. 旧路径不传 candidates 时，行为完全不变
2. 新路径传 candidates 时，走 prior-conditioned detector

### 7.2 `cellSAM_source/cellSAM/AnchorDETR/models/anchor_detr.py`

#### 当前函数

1. `class AnchorDETR(nn.Module)`
2. `forward(self, samples: NestedTensor)`

#### 建议改法

改为：

```python
def forward(
    self,
    samples: NestedTensor,
    candidate_points=None,
    candidate_valid_mask=None,
    prior_mode: str = "strict",
):
    ...
```

具体要求：

1. 把 `candidate_points / candidate_valid_mask / prior_mode` 传给 transformer
2. 在 `outputs_class` / `outputs_coord` 生成后，对无效 query 做 mask

第一版推荐：

1. 对 `candidate_valid_mask == 0` 的 query
2. 把 cell class logits 压到很低，例如 `-12`
3. 这样 matcher 和 postprocess 会自动把它们视为 no-object

这样做的好处：

1. 不需要先改 Hungarian matcher
2. 先把 prior-only detector 跑通

### 7.3 `cellSAM_source/cellSAM/AnchorDETR/models/transformer.py`

#### 当前函数

1. `class Transformer(nn.Module)`
2. `forward(self, srcs, masks)`

#### 建议改法

改为：

```python
def forward(
    self,
    srcs,
    masks,
    candidate_points=None,
    candidate_valid_mask=None,
    prior_mode: str = "strict",
):
    ...
```

新增内部 helper：

```python
def _build_reference_points(
    self,
    bs: int,
    device,
    candidate_points=None,
    candidate_valid_mask=None,
    prior_mode: str = "strict",
):
    ...
```

实现要求：

1. `strict`
   - 全部 query reference points 来自 candidates
   - 不足部分允许 padding，但这些 padding query 必须由 `candidate_valid_mask` 标成无效
   - 不默认用 learned fallback queries
2. `hybrid`
   - 仅对无效 query 位置回退到 learned positions
3. 默认值：
   - `prior_mode="strict"`

## 9. 第一版实验顺序

### Phase P0. 冻结先验

1. 导出 `adaptive locked_eval` candidates
2. 导出 `dapi_cm locked_eval` candidates
3. 统计：
   - 每图 candidate 数
   - 与 GT 框匹配率
   - 边缘过滤比例
   - 双核比例

### Phase P1. 跑通 prior-conditioned detector

1. `strict prior-only`
2. 不开 fallback
3. 验证 detector forward 不崩
4. 验证输出 boxes 合理

### Phase P2. detector 指标

1. `adaptive candidates + CellFinder refinement`
2. 对比：
   - `raw CellFinder`
   - `adaptive boxes`
   - `prior-conditioned CellFinder`

### Phase P3. downstream E2E

1. 选 `T27a` 先接上
2. 再看是否切到 `T29c/T30`

## 10. 成功标准

第一阶段必须满足：

1. 不传 candidates 时，旧 `CellFinder` 行为不变
2. 传 candidates 时，`strict prior-only` 跑通
3. detector 输出数量与 candidate 数基本一致
4. 明显降低 `FP`

第二阶段再看：

1. detector `AP50 / mAP`
2. downstream `E2E PQ`

## 11. 不要做的事

1. 不要把 `H1bA` 写成 released `CellFinder` 原生支持
2. 不要一开始就同时改 loss、LoRA、segmentation encoder
3. 不要默认混入大量 learned fallback queries
4. 不要在线生成 candidates 直接训练
5. 不要静默修改 `test` GT

## 12. 与 `A1-H1a` 的边界

`A1-H1b` 负责：

1. 完整 `DAPI + Actn2` candidate 先验接入
2. `CellFinder` query prior 改造
3. detector-level refinement

`A1-H1b` 不负责：

1. 外部轻量 regressor 原型
2. `H2` 标注质控
3. noisy-box segmentation 训练
