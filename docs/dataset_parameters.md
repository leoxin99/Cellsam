## 4. 细胞尺寸统计 (GT 全集分析)

> ⚠️ **分辨率换算**: 原始统计在 1736×1776 分辨率。训练使用 1024×1024。
> **面积换算系数**: (1024 / √(1736×1776))² = (1024/1756)² = **0.340**（分母取宽高几何均值）

| 统计量 | 原始 (1736×1776) | 训练用 (1024px) | 备注 |
|--------|------------------|-----------------|------|
| **最小值** | 6,240 | 2,122 | 可能包含标注错误 |
| **P1** | 40,836 | **13,884** | **推荐最小阈值** |
| **中位数** | 142,316 | 48,387 | 典型细胞大小 |
| **P99** | 513,928 | **174,735** | **推荐最大阈值** |
| **最大值** | 1,026,328 | 348,952 | 可能包含合并错误 |

## 5. 细胞核统计 (DAPI, Dev Set 50 张)

> ⚠️ **分辨率换算**: 训练使用 1024×1024。下表为两种分辨率对比。  
> 说明: 此处原始分辨率表头曾误写为 1608px，已按 2026-02-05 结论统一为 1736×1776 口径。

| 统计量 | 原始 (1736×1776) | 训练用 (1024px) | 备注 |
|--------|--------------|-----------------|------|
| **最小值** | ~100 | ~50 | 检测下限 |
| **P1** | 112 | 57 | 过滤噪点阈值 |
| **中位数** | 9,324 | **3,268** | 典型核大小 |
| **P99** | 29,036 | **10,026** | 过滤粘连阈值 |
| **最大值** | 53,756 | 18,281 | 含异常 |

| 参数 | 代码默认值 | Val 消融候选 (E34) | 说明 |
|------|-----------|-------------------|------|
| **min_nucleus_area** | 200 | **1,500** | Dev P1 统计 → val 消融上调 |
| **max_nucleus_area** | 10,000 | **20,000** | Dev P99 统计 → val 消融上调 |
| **核/细胞面积比** | ~5.7% | — | 3268 / 57699 |

> ⚠️ 三级参数体系: `代码默认值`(dapi.py 签名) → `Val 消融候选`(E34 结果) → `Test 封板值`(待 T1 完成)。
> 当前 val 候选尚未写入代码默认值，运行消融脚本时通过 CLI `--min-nucleus-area 1500 --max-nucleus-area 20000` 传入。

## 6. 边缘过滤参数 ⭐ (Dev Set Refined)

**来源**: Dev Set 50 张, 有效 GT 核 (area >= 5000 px)

> ⚠️ 口径说明: 本节是历史统计参考，不是 E34 当前锁定参数。  
> E34 当前检测调参在 `val(71)` 上进行，边缘参数 retune 属于下一轮计划项。

| 30px | 0.0% | 过于保守 |

| 100px | 5.6% | 之前版本 |
| 150px | 16.3% | 排除过多 |

## 7. 双核合并参数 ⭐ (Dev Set Refined)

**来源**: Dev Set 50 张, 有效配对 (area >= 5000 px, ratio < 3.0)

> ⚠️ 口径说明: 本节是历史统计参考，不是 E34 当前锁定参数。  
> 当前代码仍使用 `size_ratio_threshold=3.0` + 相对距离阈值，需在后续 E34b/E35 做 val 集联合消融复核。

| 统计量 | 值 | 说明 |
|--------|-----|------|
| **核间距 Mean** | 161.3 px | |
| **核间距 P75** | 159.9 px | |
| **核间距 P95** | 322.1 px | 包含离群值 |

**结论**:
- 当前使用 **1.2×直径** (约 136px) 作为合并阈值
- 此设置较保守，避免误合并相邻细胞
