# Allen Dataset 参数文档

> **目的**: 记录数据集的常用信息和参数，供实验和代码开发参考
> **数据集**: Allen Segmented Fields (Full)
> **最后更新**: 2026-01-25

---

## 1. 数据集基本信息

| 属性 | 值 | 来源 |
|------|-----|------|
| **图像数量** | 478 张 | `data/raw/allen_segmented_fields_full` |
| **细胞总数** | 5173 个 | E17 统计 |
| **图像尺寸** | 1608 × 1608 像素 | TIFF 检查 |
| **通道数** | 10 个 | TIFF 检查 |
| **像素大小** | ~0.108 μm/px | 63X 物镜估算 |
| **位深度** | 16-bit | TIFF 检查 |

---

## 2. 数据划分 ⭐ (2026-01-25)

**文件**: `data/splits/split_v1.json`

| 集合 | 数量 | 范围 | 用途 |
|------|------|------|------|
| **Dev Set** | 50 张 | 前 50 张 | 参数推导、统计分析 |
| **Train Set** | 400 张 | 前 400 张 | 模型训练 (含 Dev) |
| **Test Set** | 78 张 | 第 401-478 张 | 独立评估 |

> ⚠️ **策略**: Dev ⊂ Train，Test 完全独立。参数从 Dev Set 推导，避免数据泄露。

---

## 3. 通道映射 (已验证)

| 通道 | 内容 | 用途 |
|------|------|------|
| **Ch0** | Brightfield | 形态观察 |
| **Ch1** | **Actn2 (α-actinin)** | Z-线检测、心肌细胞识别 |
| **Ch4** | **DAPI** | 细胞核定位 |
| **Ch5** | 空 (全零) | ❌ 不可用 |
| **Ch8** | 背景掩膜 (疑似) | 待确认 |
| **Ch9** | **GT 实例掩膜** | 训练标签 |

> ⚠️ **注意**: Ch5 在部分文档中标记为 Actn2，但实际为空。实际 Actn2 在 Ch1。

## 4. 细胞尺寸统计 (GT 全集分析)

> ⚠️ **分辨率换算**: 原始统计在 1608×1608 分辨率。训练使用 1024×1024。
> **面积换算系数**: (1024/1608)² = **0.4055**

| 统计量 | 原始 (1608px) | 训练用 (1024px) | 备注 |
|--------|--------------|-----------------|------|
| **最小值** | 6,240 | 2,530 | 可能包含标注错误 |
| **P1** | 40,836 | **16,559** | **推荐最小阈值** |
| **中位数** | 142,316 | 57,699 | 典型细胞大小 |
| **P99** | 513,928 | **208,378** | **推荐最大阈值** |
| **最大值** | 1,026,328 | 416,176 | 可能包含合并错误 |

## 5. 细胞核统计 (DAPI, Dev Set 50 张)

> ⚠️ **分辨率换算**: 训练使用 1024×1024。下表为两种分辨率对比。

| 统计量 | 原始 (1608px) | 训练用 (1024px) | 备注 |
|--------|--------------|-----------------|------|
| **最小值** | ~100 | ~50 | 检测下限 |
| **P1** | 112 | 57 | 过滤噪点阈值 |
| **中位数** | 9,324 | **3,268** | 典型核大小 |
| **P99** | 29,036 | **10,026** | 过滤粘连阈值 |
| **最大值** | 53,756 | 18,281 | 含异常 |

| 参数 | 1024 推荐值 | 说明 |
|------|-------------|------|
| **min_area** | **200** | 略高于 P1 (安全余量) |
| **max_area** | **10,000** | 约等于 P99 |
| **核/细胞面积比** | ~5.7% | 3268 / 57699 |

## 6. 边缘过滤参数 ⭐ (Dev Set Refined)

**来源**: Dev Set 50 张, 有效 GT 核 (area >= 5000 px)

| 阈值 | 排除 GT 核 | 说明 |
|------|-----------|------|
| 30px | 0.0% | 过于保守 |
| **50px** | **1.3%** | ✅ 当前使用 (平衡 Precision/Recall) |
| 100px | 5.6% | 之前版本 |
| 150px | 16.3% | 排除过多 |

## 7. 双核合并参数 ⭐ (Dev Set Refined)

**来源**: Dev Set 50 张, 有效配对 (area >= 5000 px, ratio < 3.0)

| 统计量 | 值 | 说明 |
|--------|-----|------|
| **核间距 Mean** | 161.3 px | |
| **核间距 P75** | 159.9 px | |
| **核间距 P95** | 322.1 px | 包含离群值 |

**结论**:
- 当前使用 **1.2×直径** (约 136px) 作为合并阈值
- 此设置较保守，避免误合并相邻细胞
